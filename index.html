Help & Support

1. Getting Started

PrismDesk uses a dual-pane layout. The left pane holds Tools, References, and Call Workflows; the right pane holds Quick Notes items (EOD Report, Note Bank, Daily Review Sheet). Each pane keeps its own set of tabs, so you can have a reference tool open on one side while working a call workflow or logging notes on the other.

2. Opening & Arranging Tabs

Use the menus in the top bar — Call Workflows, Quick Notes, and the Tools/References menu — to open items as tabs. Selecting an item opens it in its designated pane and the menu closes automatically. Click a tab to switch to it, or click the × on a tab to close it.

Open tabs can be dragged left or right to reorder them — click and hold a tab, drag it to where you want it, and drop it. This only reorders tabs within the same pane; tabs can't be dragged between the left and right pane.

3. Global Search

The search bar in the top-right scans the entire app as you type — not just menu items. It searches:

  • Menu items — jumps straight to that tool/workflow tab
  • Provider Directory — matches on name, title, NPI, MA, Staff Login, Workman's Comp / Self Pay status, body parts covered and excluded, procedures, and clinical rules text. Clicking a result opens that provider's full detail view directly.
  • Insurance Checker — matches on plan name and status. Clicking a result opens the tab and filters the list down to that plan.
  • Locations, Contacts & Surgery Schedulers — clicking a result opens Locations & Contacts and scrolls to / briefly highlights the matching row.
  • Note Bank — searches the full saved text of every note, not just what's visible on the card.
  • Daily Review Sheet — matches on name, DOB, or chart number.

Results are grouped by category with the matched text highlighted. Use ↑ / ↓ to move through results and Enter to jump to the highlighted one, or click any result directly. Press Escape or click elsewhere to close the dropdown.

4. Agent ID

The AGENT ID field in the top-right (also editable from Settings, under "Agent Name / ID" — both stay in sync) is used by the Clinical History Inquiry tool, where it's automatically appended to the end of the generated summary line so the output is traceable to whoever pulled it. It's saved automatically and persists across sessions.

5. EOD Report & Call Dispositions

Paste raw patient info to auto-parse Name/DOB/Chart#/Phone, select the applicable call disposition(s) (hover each for a description of what it covers), and write your agent notes. Disposition selection is based on the caller's original intent, even if the call resolved differently.

A separate "Add to Daily Review Sheet" radio group (Schedule / Reschedule / Cancellation / None) lets you also route this entry into the Daily Review Sheet in one step — submitting saves to both Note Bank and, if a category is selected, the Daily Review Sheet at the same time.

6. Note Bank

Every submitted note lands here, filterable by date range. Each entry can be edited in place — including changing (or setting) its Daily Review Sheet category after the fact, which automatically creates, moves, or removes the linked Daily Review Sheet entry to match. Deleting a note also removes its linked entry, so nothing is left orphaned.

7. Daily Review Sheet

Mirrors your spreadsheet's three columns — Schedule, Reschedule, Cancellation. Each entry can be edited, copied individually, or copied as a whole column via Copy All (formatted so pasting into Excel/Sheets keeps each entry as one properly wrapped cell, not split across rows). Use the date filter to narrow which entries show, copy, or export; leaving it blank includes everything. Export All to Excel downloads a real .xlsx file with one sheet per column. Clear All wipes every entry (with a confirmation prompt) and automatically unlinks any Note Bank entries pointing at what was cleared.

8. Provider Directory & Insurance Checker

Both tools support adding, editing, and removing entries — changes save automatically and persist across tab closes and page reloads. Provider cards show Name/Title/NPI, MA/Workman's Comp/Self Pay/Staff Login, and body parts covered/excluded at a glance; click a card for the full detail view. In Insurance Checker, use the toggle action to move a plan between Accepted and Unaccepted.

9. Settings

Click the ⚙️ icon to open Settings in a slide-out panel. From here you can switch between light and dark mode (the browser tab's favicon updates to match automatically), adjust font size, set your Agent Name/ID, and export your activity log. Closing the panel fully collapses it — nothing stays open in the background.

How do I switch between light and dark mode?
Open Settings (⚙️ icon, top right) and use the theme toggle. Your choice is saved automatically, and the browser tab's icon updates to match.
What all does the search bar actually search?
Everything: menu items, Provider Directory (including MA, NPI, Staff Login, body parts, and procedures), Insurance Checker, Locations & Contacts, Surgery Schedulers, Note Bank content, and Daily Review Sheet entries. Clicking a result takes you straight to the matching item, not just the tab.
How do I find a location's address or phone number quickly?
Type the location or contact name into the top search bar. Clicking the result opens Locations & Contacts and scrolls straight to it.
How can I tell if an insurance plan is accepted?
Search the plan name in the top search bar — its status (Accepted/Unaccepted) shows right under the name in the dropdown. Clicking it opens Insurance Checker filtered to just that plan.
What does the AGENT ID field actually do?
It's appended automatically to the summary line generated by the Clinical History Inquiry tool. It's shared with Settings — updating it in either place updates both — and saves automatically.
Why did a tab I closed lose its info?
Most tabs reset when closed and reopened, but Note Bank, Daily Review Sheet, Insurance Checker, and Provider Directory all save automatically and persist across tab closes and page reloads.
I have a lot of tabs open — how do I organize them?
Drag a tab left or right to reorder it within its pane. The tab bar also scrolls horizontally if you have more open than fit. Reopening an item that's already open just switches to it instead of duplicating it.
Can I open the same tool on both panes at once?
Each tool is assigned to a specific pane (left or right) based on its menu, so it will always open on that side. This keeps reference tools and active workflows separated.
How do I get my Daily Review Sheet entries into the actual spreadsheet?
Use Copy (single entry) or Copy All (whole column) — both are formatted so a normal paste keeps each entry in one wrapped cell instead of splitting across rows. For a clean, guaranteed-correct result regardless of paste behavior, use "Export All to Excel" to download a real .xlsx file instead.
If I edit a note in Note Bank, does it update the Daily Review Sheet too?
Yes, if it's linked to one. Changing the category while editing moves it to the right column (or creates/removes the link), and editing the note's text refreshes the linked entry's Name/DOB/Chart# automatically.
